# Diwali Sales Analysis

## Project Overview
This project analyzes Diwali sales data to identify customer purchasing behavior and business insights.

##  Tools Used
 Python
 Pandas
 NumPy
 Matplotlib
 Seaborn

## Analysis
 Data Cleaning
 Gender-wise Analysis
 Age Group Analysis
 State-wise Analysis
 Occupation Analysis
 Product Category Analysis

## Key Insights
 Female customers purchased more than male customers.
 Customers aged 26–35 made the highest purchases.
 Uttar Pradesh, Maharashtra, and Karnataka had high sales.
 IT, Healthcare, and Aviation customers spent more.
